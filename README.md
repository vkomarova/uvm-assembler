# Ассемблер для учебной виртуальной машины (УВМ)

## Общее описание

Проект — ассемблер для учебной виртуальной машины (УВМ).
Этап 1: ассемблер читает программу на языке ассемблера (формат JSON)
и переводит её во внутреннее представление — список словарей с полями
`A`, `B`, `C`, `D`, как в спецификации УВМ.

Структура проекта:

```
src/assembler.py         — ассемблер
tests/test_assembler.py  — тесты
tests/spec_test.json     — программа с тестами из спецификации УВМ
run.sh, run.bat          — скрипты запуска
Makefile                 — команды запуска и тестов
```

## Язык ассемблера

Программа - это JSON-массив. Каждый элемент массива - одна команда
в виде объекта. Поле `command` задает имя команды, остальные поля -
её операнды. Все значения - целые неотрицательные числа.

Команды:

1. `load` — загрузка константы.
   - Пример: `{"command": "load", "address": 106, "value": 723}`
   - Поля УВМ: A=14, B=address, C=value
   - Действие: `mem[address] = value`
2. `read` — чтение значения из памяти.
   - Пример: `{"command": "read", "base": 183, "offset": 438, "dest": 923}`
   - Поля УВМ: A=12, B=base, C=offset, D=dest
   - Действие: `mem[dest] = mem[mem[base] + offset]`
3. `write` — запись значения в память.
   - Пример: `{"command": "write", "offset": 694, "base": 172, "src": 732}`
   - Поля УВМ: A=11, B=offset, C=base, D=src
   - Действие: `mem[mem[base] + offset] = mem[src]`
4. `neg` — унарный минус.
   - Пример: `{"command": "neg", "offset": 124, "base": 423, "src": 97}`
   - Поля УВМ: A=6, B=offset, C=base, D=src
   - Действие: `mem[mem[base] + offset] = -mem[src]`

Значения полей:

- `address` — адрес ячейки памяти, куда записывается константа;
- `value` — константа;
- `base` — адрес ячейки памяти, в которой лежит базовый адрес;
- `offset` — смещение, которое прибавляется к базовому адресу;
- `dest` — адрес ячейки памяти для результата;
- `src` — адрес ячейки памяти с исходным значением.

Пример программы:

```json
[
    {"command": "load", "address": 106, "value": 723},
    {"command": "read", "base": 183, "offset": 438, "dest": 923},
    {"command": "write", "offset": 694, "base": 172, "src": 732},
    {"command": "neg", "offset": 124, "base": 423, "src": 97}
]
```

## Функции и настройки

Аргументы командной строки ассемблера:

```
python3 src/assembler.py <source> <output> [--test]
```

- `source` — путь к исходному файлу с текстом программы (JSON);
- `output` — путь к двоичному файлу-результату;
- `--test` — режим тестирования: вывести на экран внутреннее
  представление программы в формате полей и значений.

Функции в `src/assembler.py`:

- `translate_command(command)` — переводит одну команду JSON в словарь
  с полями УВМ;
- `translate_program(commands)` — переводит список команд во внутреннее
  представление;
- `read_program(path)` — читает JSON-файл с программой;
- `format_fields(fields)` — возвращает строку вида `A=14, B=106, C=723`;
- `print_program(program)` — выводит внутреннее представление на экран;
- `parse_args()` — разбирает аргументы командной строки;
- `main()` — точка входа.

## Сборка и запуск тестов

Сборка не нужна, нужен только Python 3.

Запуск ассемблера на программе из спецификации:

```
make run        # или ./run.sh (Linux/macOS), или run.bat (Windows)
```

Запуск тестов:

```
make test
```

или без make:

```
python3 -m unittest discover -s tests -v
```

## Примеры использования

```
$ python3 src/assembler.py tests/spec_test.json program.bin --test
A=14, B=106, C=723
A=12, B=183, C=438, D=923
A=11, B=694, C=172, D=732
A=6, B=124, C=423, D=97
```

Вывод совпадает с тестами из спецификации УВМ:

- Загрузка константы: `A=14, B=106, C=723`
- Чтение значения из памяти: `A=12, B=183, C=438, D=923`
- Запись значения в память: `A=11, B=694, C=172, D=732`
- Унарный минус: `A=6, B=124, C=423, D=97`
